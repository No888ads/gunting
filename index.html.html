Sambungan Firebase Realtime Database (Perkongsian Data Semua 71 Anggota)

Masukkan Firebase Database URL (atau objek firebaseConfig) anda di bawah supaya semua anggota melihat status & resit secara langsung (Real-Time) di telefon masing-masing.

Status: Menunggu URL Firebase
Cara Setup Pantas (2 Minit):
  1. Buka console.firebase.google.com & buat projek baharu.
  2. Pergi ke menu Build → Realtime Database → Create Database (pilih rantau Singapore / asia-southeast1 & Start in Test Mode).
  3. Salin pautan URL https://...-default-rtdb...firebasedatabase.app dan tampal di ruangan sebelah (atau terus letak dalam pembolehubah PRESET_FIREBASE_CONFIG di dalam kod HTML sebelum muat naik ke GitHub Pages).
